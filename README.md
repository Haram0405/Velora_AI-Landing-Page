# 📖 Overview

Velora AI is a premium AI SaaS landing page designed to showcase a modern AI assistant with a clean, elegant, and user-focused interface.

The project focuses on creating a realistic startup-style experience through thoughtful layouts, smooth animations, responsive design, and polished UI interactions.

This project demonstrates modern frontend development practices using React, Vite, Tailwind CSS, and Framer Motion.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Haram0405/Velora_AI-Landing-Page.git
```

---

## Navigate

```bash
cd Velora_AI-Landing-Page
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```
